## How to Use This Plan
1. Follow the daily schedule exactly as outlined
2. Complete all study, practice, and hands-on activities
3. Push your work to GitHub daily using the provided scripts
4. Review and reinforce concepts regularly
5. Prepare for behavioral questions alongside technical preparation

## Prerequisites
- AWS Free Tier account
- GitHub account
- Basic Linux/CLI knowledge
- Text editor (VS Code recommended)
- Internet access

## Services Covered
- **Compute**: EC2, Lambda, Elastic Beanstalk
- **Storage**: S3, EBS, EFS
- **Database**: RDS, DynamoDB
- **Networking**: VPC, Route 53, CloudFront, ELB
- **Security**: IAM, KMS, WAF, Shield
- **Management**: CloudFormation, CloudWatch, CloudTrail
- **Analytics**: Athena, QuickSight
- **Migration**: DMS, Snowball
